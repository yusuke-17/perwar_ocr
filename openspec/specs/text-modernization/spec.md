# text-modernization Specification

## Purpose

正規化済みの戦前の文章を LLM で現代の口語体に書き換えるときの振る舞いを定める。長い文章を LLM に渡せる大きさに分ける方法と、
LLM に渡さずに残す行の扱いを定め、`prewar ocr` と `prewar fix` のどちらから使っても原文の字が増えたり、欠けたページの前後がつながったりしないことを保証する。

## Requirements

### Requirement: 分割で原文に字を足さない
システムは長い文章を LLM に渡す断片に分けるとき、原文に無い字（句点など）を加えてはならない（MUST NOT）。
断片を順につなぐと、分ける前の文章と一字も違わないものにならなければならない（SHALL）。

#### Scenario: 句点で終わらない長文
- **WHEN** 「。」で終わらない 2,000 字を超える旧字体・カタカナ文語の文章を口語化する
- **THEN** LLM に渡る最後の断片の末尾に「。」は付かない

#### Scenario: 変換に失敗した断片が原文のまま残る
- **WHEN** 「。」で終わらない長文の最後の断片だけ LLM の呼び出しに失敗する
- **THEN** 口語化テキストの末尾にはその断片の原文がそのまま残り、原文に無い「。」は付かない

### Requirement: 目印の行を変換しない
システムは読み取れなかったページの目印の行を LLM に渡してはならず（MUST NOT）、口語化テキストの同じ位置に一字も変えずに残さなければならない（SHALL）。
目印の前の本文と後の本文を同じ断片に入れてはならず（MUST NOT）、目印の行の前後の空行は残さなければならない（MUST）。

#### Scenario: 途中に目印がある
- **WHEN** 文の途中で途切れた本文、「〔第2頁 読み取り失敗（IMG_0002.png）〕」、文の途中から始まる本文の順に並ぶ文章を口語化する
- **THEN** 目印の前後の本文は別々の LLM 呼び出しで変換され、口語化テキストには変換後の前の本文、空行、目印の行、空行、変換後の後の本文の順に並ぶ

#### Scenario: 目印を含むテキストを後から変換する
- **WHEN** 目印を含む OCR 生テキストのファイルを `prewar fix` で口語化する
- **THEN** 目印の行は一字も変わらずに残り、目印をまたいで 1 つの断片にはならない

#### Scenario: 目印だけの文章
- **WHEN** 本文が目印の行だけの文章を口語化する
- **THEN** LLM は呼び出されず、目印の行がそのまま口語化テキストになる
