# Spec Delta

## ADDED Requirements

### Requirement: お手本の混入を見つけてお手本なしで変換し直す
システムは口語化した断片の結果に、LLM に渡したお手本由来の語が含まれ、かつその断片の原文に対応する語が無いとき、その結果を採用してはならない（MUST NOT）。
設定 `chunk.retry_without_examples`（既定 true）が有効なら、その断片をお手本を渡さずに 1 回変換し直し、その結果を判定せずに採用しなければならない（SHALL）。
最初の変換はお手本つきで行わなければならない（SHALL）。変換し直したことは画面に知らせなければならず（SHALL）、記録の `meta.json` に何も足してはならない（MUST NOT）。

#### Scenario: お手本つきの結果に混入する
- **WHEN** 話の途中から始まるカタカナ文語の断片（例「是ニ於テ其ノ夜師ヲ訪ネテ教ヲ乞フ。」）のお手本つきの変換結果に、原文に無い「その流派の創始者は常陸国の出身で…」が含まれる
- **THEN** お手本を LLM に渡さずに変換し直し、口語化テキストにはその結果が入る
- **AND** 画面に混入を見つけて変換し直した旨が表示され、`meta.json` に失敗の記録は足されない

#### Scenario: 引用が断片の境目で切れている
- **WHEN** 教育勅語の引用が断片の境目で切れ、「皇祖」が前の断片にある断片の訳に「皇室の祖先」が含まれる
- **THEN** お手本つきの結果は混入とみなされるが、お手本なしの結果は判定せずに採用され、正しい訳が口語化テキストに残る

#### Scenario: 原文が実際に引用している
- **WHEN** 原文の断片が「其ノ流祖ハ常陸國ノ人ニシテ…」を含み、変換結果に「常陸国」が含まれる
- **THEN** 混入とみなさず、お手本つきの結果をそのまま採用する

#### Scenario: 本物の租税の文
- **WHEN** 原文の断片が「日本國民ハ租税ヲ納ムルノ義務ヲ負フ。」で、変換結果に「日本の国民は」と「税金を納める義務」が含まれる
- **THEN** 原文に「税」があるので混入とみなさず、その結果を採用する

### Requirement: 変換し直さない設定では混入した断片を原文のまま残す
システムは `chunk.retry_without_examples` が false のとき、混入を見つけた断片を変換に失敗した断片と同じく原文のまま口語化テキストに残さなければならない（SHALL）。
その断片は失敗として数えて `meta.json` の `failed_chunks` に含め（SHALL）、画面には失敗の理由がお手本の混入であることを示さなければならない（SHALL）。
`chunk.on_error` が `abort` のときは、ほかの失敗と同じく変換全体を中止しなければならない（SHALL）。

#### Scenario: 変換し直さない
- **WHEN** `chunk.retry_without_examples = false` で、ある断片の変換結果に原文に無い「皇室の祖先が国を開いた」が含まれる
- **THEN** 変換し直さず、その断片は旧字体・カタカナの原文のまま口語化テキストに残り、ほかの断片は変換結果が入る
- **AND** 画面にはその断片の失敗の理由としてお手本の混入が示され、`meta.json` の `failed_chunks` は 1 になる

#### Scenario: 中止の方針
- **WHEN** `chunk.retry_without_examples = false` かつ `chunk.on_error = "abort"` で、ある断片の変換結果に混入がある
- **THEN** 口語化は中止され、ほかの失敗と同じく呼び出し元に失敗が伝わる
